## Безопасность

- [ ] Проверена аварийная кнопка.
- [ ] Есть механический страховочный ограничитель маятника.
- [ ] Есть ограничители положения тележки.
- [ ] Команда 0 проверена без риска самопроизвольного движения.
- [ ] Направления датчиков и двигателя проверены отдельно.
- [ ] Определены допустимые пределы `x`, `x_dot`, `theta`, `theta_dot`, тока и температуры.
- [ ] Определено условие безопасного сброса после `FAULT`.
